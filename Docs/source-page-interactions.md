# 书源页交互调整

## 四项改动

1. **统一添加入口**：右上角加号与列表顶部「添加书源」打开同一个面板，提供在线合集、订阅链接、粘贴 JSON、单次链接导入与示例。订阅管理和发现页检测移到列表顶部。选择添加方式后，先关闭面板再打开表单；导入结果等待表单关闭后展示。
2. **搜索自动展开**：搜索时所有匹配分组展开，不修改用户原先的折叠记录；清空搜索后恢复。同步修正搜索框的「书名」为「书源名称」。
3. **书源详情页**：点书源名称先查看站点、分组、来源、启用与置顶状态、规则兼容性、发现页检测和关联书籍；「高级编辑规则」才进入规则表单。详情读取当前书源，编辑保存后会更新；删除提示说明对书架后续下载的影响。
4. **检测结果独立展示**：检测页提供进度、停止操作，以及可打开、异常、未检测和已停止分区；缺少发现页配置不会归为异常。检测不修改启停状态，也不自动进入批量选择。点击「选择异常书源进行批量管理」后才进入原有批量流程。

检测仍只验证发现页，不能推断整个书源或正文是否可用；结果仅保存在当前页面会话。

## 检查与验收

- 修改的 Swift 文件通过 tree-sitter 语法解析；`git diff --check` 通过。
- 新增 iOS 条件测试：未配置发现页不标记失败；立即取消及重启时旧检测任务不能改写新状态。
- 环境缺少 Swift 工具链和 iOS SDK，未执行编译、单测与真机界面测试；语法解析不能替代类型检查。

真机重点检查：

1. 分别从加号和顶部入口打开添加面板，检查各入口、取消后重开、导入结果弹窗。
2. 先手动展开一个大分组、收起另一个，再搜索并清空，确认原状态恢复；检查置顶项不重复。
3. 点书源、切换启用和置顶、进入高级编辑保存，检查返回详情后的状态；列表开关不应打开详情。
4. 检测期间停止或关闭结果页，再重新检测，检查取消请求不再更新结果。
5. 混合测试可用、网络失败与无发现页配置的书源，确认分类正确；未主动选择批量管理前不改变选择或启停状态。
6. 有关联书籍时检查单个删除的影响提示；检测异常不应被描述为正文不可用。
