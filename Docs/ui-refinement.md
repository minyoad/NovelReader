# 界面易用性调整

按照书架、搜索、发现、朗读设置、阅读工具栏、误操作保护的顺序整理。

## 本轮行为

- 书架顶部增加继续阅读卡片，显示最近阅读书名、章节及本地估算进度。首次无记录时不虚构继续阅读记录。空书架提供搜索和添加书源按钮；搜索按钮也在书架右上角常驻。书源异常提示移到网格外，独占整行；书名允许两行，进度文字不再强行缩小。
- 搜索复用已有保守书籍身份规则，以同名同已知作者聚合，保留所有来源版本。不同作者、未知作者不会简单合并。多版本进入选择页，结果继续返回时选择页同步更新；单版本沿用预览/书架详情路径。失败原因按需展开，空结果或失败页提供查看原因和管理书源。
- 发现首屏增加搜索入口，分为推荐和榜单。来源选择、按书源浏览和刷新收进推荐页筛选菜单。切换榜单会取消推荐页的后台任务，榜单继续沿用自己的缓存。显示短状态和重试操作，保留榜单原网页入口。
- 朗读引擎变为单行导航选择：系统、Edge、Azure、豆包在常用服务，CosyVoice、自定义接口在更多服务。未配置项显示需配置，已配置只提示可以试听，不宣称服务已连接。服务说明按需展开；语速显示按合成倍率换算，原始参数 0.5 显示 1.0×。
- 阅读页返回、更多及顶部操作点击区域扩大到至少 44pt，设置改名为阅读样式，文字使用动态字号样式。全应用统一操作强调色，阅读页使用阅读主题自己的强调色；搜索简介提高次要文字对比层级。
- 移出书架后在当前书架提供 8 秒撤销。窗口期间只暂时隐藏卡片，书籍、进度和缓存不删除；撤销清除待移除状态，超时、离开书架或转入后台才提交原有移除逻辑。连续移除时提交上一项、为最新一项保留撤销机会。该窗口不跨进程恢复。
- 净化配置统一由独立弹层打开。未保存时阻止下滑关闭，取消提供保存、放弃、继续编辑；规则编辑子页返回仅返回草稿，不保存。非法规则保存显示提示。原文和净化后通过分段选项切换比较。

## 检查

`swift test --skip TextDecodingTests`：71 项 XCTest 和 413 项 Swift Testing 通过（484 项），跳过已有编码问题组。修改的 SwiftUI 文件通过 Swift 前端语法检查，差异格式检查通过。复用现有聚合和进度核心逻辑，未新增仅复述界面实现的单元测试。

当前 Linux 环境无法完成 iOS 构建及真机界面验收。设备上需重点检查：

1. 空书架找书、首次加书、继续阅读及移除撤销（含最后一本、连续移除和切后台）。
2. 同书多源、同名不同作者、未知作者；进入版本页时搜索继续返回。
3. 推荐与榜单切换、缓存恢复、来源筛选、无源及失败重试。
4. 朗读服务选择及返回、未配置提示、试听和 1.0× 倍率。
5. 阅读页窄屏、大字号、深浅色工具栏。
6. 从书架、书籍信息和阅读菜单打开净化，确认取消、下滑保护、保存、非法规则和预览切换。
